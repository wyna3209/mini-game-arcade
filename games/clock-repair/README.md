# 부우부와 기어르의 시계 수리점

부우부와 기어르가 함께 운영하는 가게에서 포켓몬 손님 15명의 주문을 수리하는 Phaser 게임입니다. 낮 주문 10건을 완료하면 밤이 되고, 다섯 유형의 밤 주문이 각각 두 번씩 무작위 순서로 찾아옵니다. 한 판에 총 20건을 수리합니다.
디자인 후보 3번의 따뜻한 목재 공방, 중앙의 큰 황동 시계, 청록색 버튼 구성을 적용했습니다. 데스크톱에서는 가로형 게임 화면, 모바일 세로 화면에서는 순서대로 쌓이는 배치를 사용하며 상단에서 전체 화면으로 전환할 수 있습니다.
부우부는 접수와 시간 감별, 기어르는 톱니바퀴 정비를 담당합니다. 두 사장님은 항상 작게 흔들리고, 성공·실패에 따라 대사가 달라집니다.
배경과 기어르는 생성한 PNG, 부우부와 손님들은 PokéAPI의 고해상도 원화 PNG입니다. 이미지는 `assets/`에 각각 저장되어 있으며 실행 중 이미지 CDN 연결은 필요 없습니다. 생성 도구에서 나머지 캐릭터 생성이 거절되어 원화를 사용했으므로 후보 이미지의 모자 등 의상과는 차이가 있습니다. 이미지 로드 실패 시 대체 아이콘으로 계속 플레이할 수 있습니다.
첫 주문은 테스트를 위해 **시계 읽기**로 배치했습니다. 피카츄의 고정된 아날로그 시계에서 시·분을 읽고, 하단 탁상형 기록계의 LCD 숫자를 눌러 입력하거나 옆면 −/＋ 버튼으로 조정한 뒤 **시각 전달하기**를 누릅니다. 초침은 숨기며 초는 입력하지 않습니다. 시작 모달과 주문서에 정답 숫자는 표시하지 않습니다. 시는 1~12, 분은 0~59이며 12시는 내부적으로 0시와 같습니다.
빈칸이나 범위를 벗어난 입력은 안내만 표시하고 추가 시간 차감은 없습니다. 유효한 오답은 기존처럼 3초 차감·콤보 초기화가 적용됩니다. 재도전 시 같은 시계가 표시되고 입력칸은 비워집니다.
두 번째 주문부터는 시계 아래 주문서의 시각과 조건을 보고 시침·분침·초침 끝의 화살촉을 드래그한 뒤 **수리 완료**를 누릅니다. 맞추기 주문에는 현재 시각 숫자 표시와 하단 바늘 선택/± 버튼이 없습니다.
각 주문은 손님 이미지·요청·기준 시각·조건을 크게 표시하는 모달로 시작합니다. **수리 시작**을 누른 순간부터 제한시간이 흐릅니다. 요청을 읽거나 완료 결과를 보는 동안에는 타이머가 멈추고 바늘도 조작할 수 없습니다.
완료 모달에는 손님 인사, 이번 수리 금액, 기본 수리비와 팁 내역, 누적 금액, **다음 주문 받기** 버튼이 표시됩니다. 다음 주문도 요청 모달을 읽고 직접 시작합니다. 시간 초과 시에는 재도전 안내 모달이 표시됩니다.
바늘 끝을 눌러 선택한 뒤 방향키로 한 칸씩 조정할 수도 있습니다.
맞추기 주문에서는 숫자 키 1·2·3으로 바늘 선택, Shift+방향키로 다섯 칸 조정, Enter로 확인합니다. 읽기 주문에서는 키보드가 숫자 입력에 사용되며 바늘 드래그·방향키 조정은 잠깁니다.

시침은 분·초에 따라, 분침은 초에 따라 실제 시계처럼 위치가 보정됩니다.
초침을 한 바퀴 돌리면 1분, 분침을 한 바퀴 돌리면 1시간이 함께 바뀝니다. 반대로 돌리면 이전 분·시로 넘어가며, 방향키도 같은 방식으로 시간을 올리고 내립니다. 11시 59분 59초 다음은 12시 0분 0초입니다.
바늘이 포개진 경우 숫자 키 1·2·3으로 선택하면 해당 바늘이 앞으로 나오며 방향키 조정도 사용할 수 있습니다. 시침은 파랑, 분침은 초록, 초침은 빨강입니다.

## 화면 구성과 에셋

- `assets/workshop-background.png`: 캐릭터와 UI를 제거한 공방 배경.
- `assets/klink-owner.png`: 투명 배경의 기어르 정비사.
- `assets/163.png`: 부우부. `25.png`, `133.png`, `143.png`, `300.png`, `251.png`, `225.png`, `131.png`, `54.png`, `39.png`, `385.png`, `92.png`, `93.png`, `479.png`, `354.png`, `94.png`: 손님 15명의 개별 투명 이미지.
- `src/pokemon.js`: 개별 캐릭터 이미지 연결과 로드 실패 처리.
- `index.html`, `src/style.css`: 독립된 대화창·간판·주문서·타이머·조작 버튼. 모든 한글과 숫자는 실제 텍스트입니다.
- `src/main.js`: Phaser로 그리는 시계판·눈금·바늘과 게임 진행.
- `src/clock-themes.js`: 손님별 시계 색상·케이스 형태·문양 15종. 손님이 바뀌면 같은 시계판을 다시 그립니다.
- `src/character-layout.css`: 운영진은 말풍선/일러스트/이름표를 별도 행으로, 손님은 그림/대화를 별도 열로 배치합니다. 모바일에서는 긴 대사에 맞춰 영역 높이가 늘어납니다.
- `src/reading-console.css`: 황동 테두리·청록색 본체·LCD·조정 버튼으로 구성한 기록계. 이미지가 아닌 실제 입력 UI이며 모바일에도 대응합니다. 전자시계 숫자체는 로컬 `assets/DSEG7Classic-Regular.woff2`를 사용합니다.

이미지의 캐릭터, 시계, 글자가 한 장에 합쳐져 있지 않아서 손님 변경이나 대화, 바늘 회전을 각각 제어할 수 있습니다. 생성 프롬프트와 이미지 출처는 `assets/README.md`를 참고하세요.

시간 초과 시 횟수 제한 없이 같은 주문을 다시 받을 수 있습니다.
잘못된 시각을 제출하면 3초가 차감됩니다.
기본 수리비는 주문 번호 × 100원 + 남은 시간(초 올림) × 10원입니다. 여기에 아래 팁이 더해집니다.

- 오답·시간 초과 없이 첫 제출에 성공하면 연속 수리 콤보가 1 증가하며 현재 콤보 × 50원을 받습니다.
- 제한시간 절반 이내에 첫 제출로 성공하면 **완벽 수리** 도장과 100원을 추가로 받습니다.
- 피카츄·딜리버드의 급행 팁과 에나비·푸린의 첫 제출 특별 팁은 위 보너스에 중복 적용됩니다.
- 오답/시간 초과 시 콤보는 즉시 0으로 초기화됩니다. 같은 주문 재도전으로 첫 제출 보너스를 다시 받을 수 없습니다. 다음 손님의 주문부터 새 콤보를 시작합니다.

주문 20건 완료 시 새벽 축하 모달에 총 수리비, 받은 팁, 최고 콤보가 표시됩니다. 주문 생성·특수 조건·보상 계산은 `src/time.js`에서 관리합니다.

프로젝트 루트에서 `npm run dev` 실행 후 `/games/clock-repair/`로 접속합니다.
`src/time.js`에서 시각 계산·주문 시각 생성, `src/main.js`에서 Phaser 화면과 진행 흐름을 수정합니다.
